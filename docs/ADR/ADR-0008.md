# ADR-0008 — CORS liberado para qualquer origem (configurável)

- **Status:** Aceito
- **Data:** 27/10/2026
- **Contexto de decisão:** [RFC-0003](../RFC/RFC-0003.md)

## Contexto

A API era consumida apenas por clientes de servidor (SDKs da OpenAI, Postman, `curl`). Para testar o streaming SSE direto do navegador, em localhost e em produção (Cloud Run), o navegador exige CORS: `POST` com `Authorization` e `Content-Type: application/json` dispara um preflight `OPTIONS`, que a API não respondia.

## Decisão

1. **`CORSMiddleware` do Starlette como middleware mais externo** da pilha (fora do log de requisição e do rate limit).
2. **Origens em `CORS_ALLOWED_ORIGINS`**, lista separada por vírgula, com padrão `*` em desenvolvimento e produção.
3. **Sem credenciais:** `allow_credentials` desligado; métodos e headers liberados; `x-request-id` e `Retry-After` expostos ao JavaScript.

## Por que é seguro

- O ataque que o CORS impede (site malicioso usando cookies/sessão do usuário) não se aplica: não há cookies, e o token Bearer só é enviado se a própria página o tiver.
- Autenticação e rate limit continuam valendo para toda requisição real; só o preflight (sem corpo, sem acesso a dados) é respondido antes deles.
- Restringir é só configuração: `CORS_ALLOWED_ORIGINS=https://app.exemplo.com` passa a rejeitar outras origens (preflight `400`, sem `Access-Control-Allow-Origin`).

## Validação (27/10/2026)

- Testes de integração: preflight com origem qualquer e `null`, `401` e `429` com headers CORS, origem restrita rejeitada.
- `playground/test-stream.html` aberto via `file://` no Chrome contra a API local: `stream=true` com os chunks chegando incrementalmente (5 → 9 → 14 → … → 110) e `stream=false` com resposta, fontes e `abstained`.

## Consequências

- **Positivas:** qualquer front-end ou página de teste consome a API sem proxy; o streaming continua sem buffer (middleware ASGI puro, ADR-0001).
- **Negativas:** qualquer site pode chamar a API **se** tiver um token; a proteção é o sigilo do token, como já era para clientes de servidor. Tokens não devem ser embutidos em front-ends públicos.
- **Alternativas descartadas:**
  - **`*` fixo no código:** exigiria deploy para restringir.
  - **Lista fixa de origens:** quebraria o teste por `file://` e por portas locais variáveis.
  - **CORS dentro do rate limit:** `429` sem headers CORS, que o navegador esconde como erro genérico.
